# Первый скан с 3DeVOK MQ

SubTerra принимает уже совмещённые сканы. На этапе захвата устройство работает в 3DeVOK Studio. Облако точек передаётся в SubTerra через ASC, цветная треугольная сетка — через PLY. Модель MQ указана в проекте; при получении проверьте обозначение на корпусе. [Форматы экспорта Studio](https://3devok.com/products-3devok-studio-scanning-software).

## До получения сканера

1. В автономной сборке для Windows x64 откройте `SubTerra.exe` из папки со всеми DLL. Для сборки из исходников используйте [команды в README](../README.md#среда-и-оборудование).
2. Нажмите «Импорт» и выберите `samples/scan-import/block-100x60x40-mm.ply`. Укажите миллиметры и «Z вверх». Проверьте габариты по X, Y, Z: **0,100 × 0,060 × 0,040 м**. Блок содержит восемь цветных вершин и двенадцать треугольников.
3. Откройте `points-with-normals-and-rgb.asc` из той же папки с теми же единицами и осью. В поле столбцов выберите «3DeVOK: X Y Z Nx Ny Nz R G B». Предпросмотр покажет цвет первой точки **#3399FF**. Габариты должны совпасть с PLY; здесь восемь точек без граней.
4. Сохраните проект в свою папку (`Ctrl+S`), откройте полученный `.subterra` через `Ctrl+O` и проверьте габариты и цвета. Если приложение предлагает вход для сохранения, используйте роль администратора проекта по [руководству](user-guide.md).

Автоматическая проверка из исходников: в PowerShell из корня проекта запустите `.\scripts\Test-StudioImport.ps1`. Ожидаются три строки `PASS`, включая отдельную проверку поворота оси Y. [Команды проверки произвольного файла](../samples/README.md).

## Когда придёт устройство

1. Сверьте модель, запишите версию Studio и прошивки. Используйте инструкции и совместимую версию ПО для фактического комплекта. [Центр загрузок производителя](https://www.3devok.com/download-center).
2. Подключите сканер по инструкции производителя. Убедитесь, что Studio его видит, и выполните предусмотренную производителем калибровку. Отсканируйте неподвижный предмет с заранее измеренным расстоянием между двумя узнаваемыми точками.
3. Завершите совмещение в Studio. Сохраните исходный проект Studio и экспортируйте ASC или PLY в отдельный файл. Запишите единицы и вертикальную ось экспорта. Для цветного ASC сверьте порядок столбцов и диапазон RGB.
4. Импортируйте файл в SubTerra и измерьте расстояние между теми же двумя точками. Сравните с контрольным измерением. Габариты по осям подходят для проверки длины только тогда, когда предмет ориентирован вдоль этих осей. При расхождении в 1000 раз проверьте выбор метров и миллиметров, при перестановке высоты и глубины — ось Y/Z.
5. Сохраните и повторно откройте проект. Для проверки передачи полезно сохранить вместе первый экспорт, настройки и результат контрольного измерения. Фактическую точность оценивайте по контрольным измерениям с учётом условий съёмки.

Прямой захват кадров по USB внутри SubTerra потребует совместимого SDK и отдельной проверки адаптера на устройстве. Описанный выше файловый маршрут работает через Studio.
