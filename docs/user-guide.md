# Краткое руководство

## Начало работы

Откройте `SubTerra/SubTerra.sln` в Visual Studio, выберите проект `SubTerra` и нажмите F5. При запуске доступна демонстрационная пещера. Для реальных данных используйте «Импорт скана».

При импорте укажите единицы файла и ось высоты. Экспортированный из SubTerra PLY содержит метры. [Учебные примеры](../samples/README.md) позволяют проверить масштаб без оборудования.

## Где находятся инструменты

- **Вид** — слои карты и обзор; **Настройки** — мышь, скорости и качество.
- **Сканер** — управление виртуальным сканированием.
- **Сканы** — исходники проекта, их положение и очистка.
- **Анализ → Поверхности** — поиск и подтверждение пола, стен и потолка.
- **Анализ → Комната** — построение плана по подтверждённым поверхностям.
- **Инструменты** справа — измерения, метки, срез, файлы и экспорт.

## Управление

ЛКМ вращает обзор, ПКМ сдвигает его, колесо приближает. В прогулке и полёте используйте WASD и мышь; Shift ускоряет движение, Q/E меняют высоту в полёте. Tab освобождает курсор, Esc завершает режим, Home возвращает общий вид. F11 включает презентацию.

Ctrl+S — сохранить, Ctrl+O — открыть, Ctrl+Z / Ctrl+Y — отменить / повторить изменение проекта.

## Доступ

Гость может открывать и осматривать данные. Для изменения проекта, сканирования, сохранения и экспорта нужен администратор. Логин — **admin**; при первом входе задаётся собственный пароль от 10 символов. Готового пароля нет.

## План комнаты

1. Импортируйте уже совмещённый скан одного помещения с правильным масштабом и вертикалью Z.
2. Найдите поверхности и подтвердите один пол, стены и при наличии один потолок.
3. Откройте «Комната», укажите название и постройте план.
4. Проверьте размеры и предупреждения, затем сохраните проект.

Пока поддерживается один выпуклый контур. Без замыкающей стены план не строится, без потолка высота неизвестна. Оранжевые участки — возможные проёмы или пропуски данных. Размеры приблизительные; ручная коррекция вершин ещё не реализована.

После изменения исходников или используемых классов план становится устаревшим. Его можно пересчитать либо вернуть прежнюю геометрию отменой действия. Для открытия файлов с новыми возможностями нужна актуальная версия приложения.
