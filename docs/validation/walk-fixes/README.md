# Проверка управления и нагрузки — 28 октября 2026

Исправлен конфликт двух контроллеров камеры: HelixToolkit обрабатывал Q/Z
напрямую, независимо от `InputBindings`, и смещал камеру по вертикали между
обновлениями `WalkNavigator`. Встроенное перемещение отключено; при прогулке
также блокируются масштабирование, изменение FOV и возврат к старой камере.

Движение считывает текущее состояние клавиш, а не зависит от автоповтора и
получения `KeyUp`. Одинаковый кадр WPF не обрабатывается дважды. Без движения
не обновляются камера и фонарь, а при шагах не создаются временные массивы.
Освобождённый курсор позволяет пользоваться клавиатурой в боковых элементах
управления. Удержание пробела, F11 и файловых сочетаний не повторяет команды.

Для неизменяемой поверхности заранее рассчитываются границы прогресса каждого
треугольника и признак среза потолка. Геометрия, материалы и правила видимости
сохранены.

## Автоматическая проверка

Release-сборка решения: 0 ошибок, 0 предупреждений. Пройдены все 97 тестов.
Новые проверки покрывают реальную обработку клавиш и отложенного перемещения
HelixToolkit при беге и повторном входе в прогулку, ввод и Tab вне сцены, отсутствие
выделений памяти на шагах, неверный ввод и видимость поверхности при перемотке
и переключении среза потолка.

В окне Release дополнительно проверены вход в прогулку, захват мыши, сочетание
Shift+W+Q+Z, освобождение курсора через Tab и возврат в обзор через Esc.
Проверочное окно закрыто; уже работавшая Debug-сборка пользователя не изменялась.

Исходный обработчик Q/Z: [HelixToolkit CameraController v3.1.2](https://github.com/helix-toolkit/helix-toolkit/blob/v3.1.2/Source/HelixToolkit.Wpf.SharpDX/Controls/CameraController.cs#L1322-L1342).
