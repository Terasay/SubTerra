# Рабочие инструменты и устойчивость — 28 октября 2026

Реализованы все шесть направлений следующей итерации. Изменения находятся в
`master`; новые ветки для этой работы не создавались.

## Поведение

- Esc и кнопка выхода из прогулки/полёта оставляют камеру возле осматриваемого
  участка с прежним направлением и FOV. Home возвращает общий вид отдельно.
- Чувствительность, инверсия вертикали, ходьба, полёт, ускорение Shift,
  адаптивное качество и автосохранение сохраняются локально между запусками.
  Недавние файлы ограничены десятью записями.
- Во время движения облако ограничено 15 тыс. точек; SSAO и тени временно
  отключены. Через 250 мс возвращаются выбранные качество и эффекты. Два
  буфера позволяют восстановить неизменённый полный просмотр без пересборки.
  FPS и интервал кадра измеряются по событиям завершения кадров; простой
  отображается отдельно. Индикатор ожидания не анимируется вне операции.
- Длительные файловые операции и генерация отменяются через кнопку/Esc.
  Отмена сохраняет прежний файл и сеанс. Запоздавший результат генератора,
  не реагирующего на отмену, не присваивается модели. Закрытие окна сначала
  отменяет текущую операцию, затем проверяет несохранённые изменения.
- Автосохранение создаёт отдельный архив восстановления раз в 20 секунд.
  Его исходный путь используется только при совпадении SHA-256 архива и
  метаданных. Несовпадение требует Save As, защищая другой пользовательский
  файл от перезаписи. Невосстановленная копия не перезаписывается новыми
  измерениями: сначала требуется восстановление либо явное удаление копии.
- Выбор координат, измерение расстояния, ручные метки и срез произвольной
  плоскостью доступны из сцены/сведений. Координаты относятся к выбранной
  видимой точке или поверхности; расстояние измеряется по прямой. Измерения
  и срез не изменяют исходные точки. Метки сохраняются схемой 3; старые
  схемы 1/2 читаются. Добавление и удаление меток требуют администратора.

## Проверка

Release-сборка решения: 0 ошибок, 0 предупреждений.
Полный финальный прогон: **121 тест пройден**, пропусков и ошибок нет.
Дополнительная проверка остановки индикатора ожидания выполнена после
этого прогона в тестах отмены операций.

Проверены сохранение настроек и списка файлов между экземплярами, сохранение
ракурса, ограничение и восстановление кэшированного облака, измерение 13-метрового
отрезка, права гостя, сохранение/восстановление ручных меток, фильтрация до
выборки, неизменность исходных точек, отмена сохранения и PLY с сохранением
старого файла, отмена неотвечающего генератора и закрытие во время генерации.
Проверен предельный сеанс с 256 метками по 120 символов и 360 перестановками.

Промежуточные запуски блокировались Windows Code Integrity из-за требований
к подписи DLL (0x800711C7); заключительный запуск той же штатной команды
тестирования прошёл. Настройки безопасности Windows не изменялись.

Проверки выполнены с отдельным `BaseOutputPath` в игнорируемом каталоге
`SubTerra.Tests/obj/interface-verification/`. Управление окнами в этой итерации
не выполнялось. Реальный FPS на разных GPU, точность выбора мышью и финальная
компоновка при разных DPI требуют ручного прогона; автоматические тесты не
подменяют эту проверку.
