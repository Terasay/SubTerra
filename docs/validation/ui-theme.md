# Оформление интерфейса — 28 октября 2026

Исправлен источник чёрных подписей на тёмном фоне: системные цвета `Expander` и отдельные стили полей,
не наследовавшие общую тему. У разделов, их заголовков и содержимого задан светлый текст;
стили координатных полей наследуют оформление `TextBox`. Отключённые кнопки и флажки остаются читаемыми.

В раскрывающихся списках исправлен показ выбранного элемента через `DisplayMemberPath` и шаблон выбора:
вместо служебного `StructureClassChoice {...}` отображается название класса.
В импортированном проекте выбор пространства показывает текущий проект вместе с доступными демонстрациями.

## Расположение инструментов

- Слева: «Вид», для симуляции «Сканер», для импортов «Сканы» и «Анализ», а также «Настройки».
- «Настройки»: чувствительность, инверсия, скорости, качество, восстановление и памятка клавиш.
- «Сканы»: исходники и их свойства, свёрнутая группа очистки и выделения.
- «Анализ»: отдельная рабочая панель с компактным списком кандидатов, классом, подтверждением и отклонением.
- Справа, «Инструменты»: измерения, метки, срез, места сценария, файлы, недавние проекты и журнал.
- Более широкие панели: 312/336 логических пикселей при размещении по краям, 304/328 при наложении.
  На узком окне используется одна панель, в том числе после уменьшения окна.

Тема использует общие цвета, скруглённые группы и поля, заметный фокус и более широкие полосы прокрутки.
Геометрия, материалы и управление камерой не перерабатывались.

## Автоматическая проверка

Release, 237 тестов без ошибок и пропусков. Проверки темы измеряют отрисованный текст в панелях
и в главном экране для симуляции и импорта: минимум 4,5:1 для включённых подписей и 3:1 для отключённых.
Также проверяются привязки, раскрытие разделов, оформление координатных полей, названия классов в списке
и выбранный импортированный проект.

Предпросмотр выполняется через WPF `RenderTargetBitmap` без создания окна приложения и управления рабочим столом.
Для главного экрана используется настоящий XAML; только `Viewport3DX` заменяется подписанной заглушкой.
Эта проверка оценивает вёрстку и цвета, а не GPU, реальный FPS или все состояния интерактивного окна.

Получить изображения локально:

```powershell
$env:SUBTERRA_UI_PREVIEW_DIR = Join-Path $PWD 'artifacts/ui-preview'
dotnet test .\SubTerra.Tests\SubTerra.Tests.csproj -c Release --filter FullyQualifiedName~ThemeRenderingTests
```

В папке появятся `workspace-panels.png`, `workspace-layout.png` и `workspace-import-layout.png`.
Это вспомогательные изображения, они исключены из Git вместе с `artifacts/`.
