# Проверка репозитория и экспорта

Дата: 25 октября 2026 года.

## Структура репозитория

Корень Git перенесён из папки приложения в корень решения. Сохранены существующие коммиты, ветка `master`, remote `origin` и его адрес. `git fsck --no-reflogs` не сообщил об ошибках. Перед переносом создана и проверена локальная резервная копия истории в Git bundle; она лежит в исключённой из Git папке `artifacts/repository-backup`.

В коммит входят приложение, проекты тестов и диагностики, документация, концепция/ТЗ и настройки GitHub Actions. Вложенных Git-ссылок вместо исходников нет. Сборки, настройки IDE, локальная учётная запись, записи сканирования и временные файлы исключены через `.gitignore`.

## Чистая сборка

В отдельную пустую папку выгружены только файлы подготовленного Git-индекса через `git checkout-index`. В ней изначально отсутствовали `bin`, `obj` и локальные настройки Visual Studio. Затем выполнены команды из workflow:

```powershell
dotnet restore .\SubTerra\SubTerra.sln --locked-mode
dotnet build .\SubTerra\SubTerra.sln --configuration Release --no-restore
dotnet test .\SubTerra.Tests\SubTerra.Tests.csproj --configuration Release --no-build --no-restore
```

Среда: Windows, SDK .NET 9.0.314. Restore завершился с зафиксированными зависимостями; Release собран без предупреждений и ошибок; **74 теста прошли**. В основном рабочем каталоге также проверена сборка Debug без предупреждений и ошибок.

Использовался локальный кэш NuGet. Проверка подтверждает полноту исходников и конфигурации, но не заменяет первый запуск на сервере GitHub Actions. Удалённый workflow ещё не запускался в рамках этой проверки.

## Сохранность PLY

Экспорт создаётся во временном файле в том же каталоге. После завершения записи существующее назначение заменяется через `File.Replace`, новое — через `File.Move`. При отказе операции временный файл удаляется. До записи проверяется конечность координат и диапазон интенсивности.

Добавлены восемь проверок:

- открытый с разрешением замены читатель продолжает видеть прежний файл, а новое открытие получает готовый экспорт;
- блокировка назначения сохраняет прежнее содержимое и не оставляет временный файл;
- NaN и бесконечные координаты, NaN и выход интенсивности за диапазон 0–1 не заменяют существующий экспорт.

Ранее проверенные формат PLY, точность чисел и десятичный разделитель продолжают проверяться в общем наборе тестов. Это проверка обычных ошибок ввода-вывода; сбой питания и особенности сетевых файловых систем не моделировались.
