# Короткая проверка интерфейса Subterra

## Прототип 0.6: роли, сохранение и перестановка датчика

Дата: 24 октября 2026 года. Release, окно 1520×960.

В обычном окне проверены запуск гостем, недоступность параметров сканера, запуска, остановки, очистки, сохранения и PLY. Пробел не запустил проход, Ctrl+S не открыл сохранение; осталось 180 кадров и 127 742 точки демонстрации. Гость смог открыть прогулку внутри пещеры. Закрытие неизменённой демосцены через Alt+F4 завершило приложение.

Автоматически проходят **66 тестов**. Новые проверки охватывают:

- создание локальной учётной записи, хеш вместо открытого пароля, неверный логин/пароль, запрет повторной настройки и повреждённый файл;
- блокировку после пяти попыток, сохранение задержки между экземплярами сервиса, истечение задержки и смену прав при входе/выходе;
- запреты гостю на уровне публичных операций и команд, открытие файла гостем, остановку потока при потере прав;
- отмену всех шести действий с несохранёнными данными, отмену выбора пути, ошибку записи/открытия, сохранение скрытых перемоткой кадров и очистку после отказа от сохранения;
- сохранение новой позы до следующего кадра, повторное открытие, точное совпадение продолженного потока, неизменность старых измерений, разрыв покрытия после перескока, объединение при возвращении, границы прогулки и её меток;
- проверку зазора от стены, ошибочный план перестановок и сохранение записи без отражений.

Debug и Release собираются без ошибок и предупреждений. Учётная запись текущего профиля Windows при проверке не создавалась; пароль задаёт пользователь.

Полный ручной проход форм создания/входа, подтверждения несохранённого сеанса и перестановки через ползунки **не выполнен**. Отдельный временный стенд администратора был собран, но инструмент управления окнами завершил ожидание разрешения запуска по тайм-ауту. Его файлы удалены. Результаты автоматических проверок не подменяют эту ручную проверку. Длительный прогон GPU/видеопамяти также остаётся в плане.

## Прототип 0.5: поток и продолжение файла

Дата: 23 октября 2026 года. Release, окно 1520×960. Проверка выполнена через обычные кнопки, временную шкалу и системные диалоги сохранения/открытия.

| Действие | Наблюдаемый результат |
|---|---|
| Запустить новый проход Авроры и сразу нажать паузу | Карта остаётся пустой, кадры после отмены не появляются. Повторный запуск доступен. |
| Запустить проход повторно | Карта и маршрут растут; наблюдались 145 из 180 полученных кадров, затем 168 при нажатии паузы. |
| Оставить проход на паузе | За последующую проверку число кадров остаётся 168; в записи 120 131 точка, время 00:16.8. |
| Перемотать к кадру 60 и включить «Точки» | Просматриваются 42 397 исходных точек этого момента; после среза показаны 22 076. Запись по-прежнему содержит все 120 131 точку. |
| Сохранить через Ctrl+S из просмотра кадра 60 | Создан частичный файл на 168 кадров, а не на 60. |
| Открыть этот файл через Ctrl+O | Восстановлены 168 кадров и 120 131 точка; доступна кнопка «Продолжить сканирование». |
| Продолжить запись из файла | Проход завершается на 180 кадрах и 127 742 точках. Повторные исходные кадры не добавляются; журнал содержит продолжение с сохранённого кадра и успешное завершение. |
| Вернуть режим «Пещера» | Цельная модель снова доступна для осмотра. |

Временный файл проверки находился в obj и удалён после загрузки. Побайтовое сохранение координат и соответствие продолженных кадров пакетному симулятору дополнительно проверены автоматическими тестами, включая нестандартные seed, плотность, плановое число кадров, старт и период. Всего проходят 42 теста. Отдельно проверены запоздавший кадр после отмены, очистка, обрыв источника, сохранение полученной части и ограничение ожидания неотвечающего источника.

Эта короткая проверка подтверждает работу перечисленных действий, но не заменяет длительный прогон интерфейса. FPS GPU, видеопамять и часовая стабильность пока не измерены. CPU-замер пополнения растущего облака добавлен в performance.md и performance.json.

## Прототип 0.4: предыдущая проверка уровней качества

Дата: 23 октября 2026 года. Сборка Release, прототип 0.4. Окно 1520×960, аппаратный вывод HelixToolkit/DirectX. Проверка выполнена через интерфейс приложения.

| Действие | Наблюдаемый результат |
|---|---|
| Открыть Аврору и включить вид «Точки» | Показаны 60 000 из 127 742 исходных точек; активен уровень «Баланс». |
| Выбрать уровень «Быстро» | Показаны 25 000 точек; запись по-прежнему содержит 127 742 точки. |
| Переключиться на шахту | Сцена загружена, показаны 25 000 из 127 222 точек. |
| Переключиться на лавовый тоннель | Сцена загружена, показаны 25 000 из 127 134 точек. |
| Перемотать тоннель к кадру 90 из 180 | Показаны 12 163 из 63 458 точек выбранного момента; записанный сеанс содержит 127 134 точки. |
| Вернуться к последнему кадру | Отображается полная полученная карта с ограничением 25 000 точек, запись не сокращается. |

Во время этого короткого прогона сообщений об ошибках отрисовки не появилось. Уровни качества и перемотка не сбрасывают записанный объём. Сохранение полного массива при ограниченном просмотре также проверяется автоматическим тестом.

Наблюдавшиеся снимки private bytes процесса: около 289 МиБ при первом просмотре Авроры, 300 МиБ после выбора «Быстро», 336 МиБ после загрузки шахты и 359 МиБ после загрузки тоннеля. Это округлённые значения из строки состояния в разные моменты времени. Они включают прогрев WPF, .NET и драйверные ресурсы; принудительный GC в окне не выполнялся.

По такой короткой последовательности нельзя сделать вывод об отсутствии утечек или о длительном росте памяти. Численные CPU-замеры с явным GC приведены отдельно в performance.md. Часовой прогон, FPS GPU, видеопамять и задержки ввода остаются непроверенными.
