# Исправление CI и операций со сканами

Дата: 28 октября 2026 года.

## Найденные причины

GitHub Actions для коммитов `e194477` и `4533639` завершился на шаге `Run tests`; восстановление зависимостей и сборка прошли успешно. В исходной локальной копии прошли 172 из 174 тестов. Подробный удалённый лог через публичный API недоступен; локально воспроизведены две ошибки:

- `LastObjectRemovalCanBeSavedAndUndone`: сохранение проверяло число кадров симулятора даже для проекта сканов. Сохранить проект после удаления последнего объекта, скрытия всех объектов или удаления всех видимых точек было невозможно.
- `DensityReductionKeepsOriginalRepresentativesAndDoesNotReincludeDeletedPoints`: деление координат `float` на размер ячейки `double` помещало граничные точки в соседнюю ячейку. Например, `0.02f / 0.01` оказывалось чуть меньше 2.

Дополнительно обнаружены:

- `samples/scan-import/block-100x60x40-mm.ply` существовал локально, но отсутствовал среди файлов Git из-за правила `*.ply`. Тест `ShippedExamplesHaveTheDocumentedSizeColorsAndTopology` требует этот файл. Для демонстрационных PLY добавлено исключение в `.gitignore`.
- `global.json` требовал SDK 10.0.400, хотя workflow устанавливает .NET 9 и все проекты используют .NET 9. Выбор SDK приведён к семейству .NET 9.
- Вершины сетки без оставшихся граней пропадали в режиме сетки, в том числе после очистки. Теперь они отображаются как точки рядом с сохранившимися гранями.
- Добавление скана могло изменить текущий проект после отзыва прав администратора во время импорта. Перед применением результата права проверяются повторно.

## Проверка исправлений

Среда: Windows, SDK .NET 9.0.320, среда выполнения .NET 9.0.22.

Добавлено 11 проверок: положительные и отрицательные границы ячеек по трём осям, вершины без граней, сохранение и повторное открытие пустого видимого проекта, отзыв прав во время добавления скана.

В отдельную пустую папку `artifacts/ci-validation-20261028` скопированы только отслеживаемые файлы и новые файлы, не исключённые из Git. Существующие `bin`, `obj`, настройки IDE и прочие игнорируемые файлы в проверку не попали. Демонстрационный PLY вошёл в эту копию.

В ней выполнены команды workflow:

```powershell
dotnet restore .\SubTerra\SubTerra.sln --locked-mode
dotnet build .\SubTerra\SubTerra.sln --configuration Release --no-restore
dotnet test .\SubTerra.Tests\SubTerra.Tests.csproj --configuration Release --no-build --no-restore
```

Результат: зависимости восстановлены в locked mode, Release собран без предупреждений и ошибок, **185 тестов прошли, 0 пропущено**. Результаты TRX сохранены в `artifacts/ci-validation-20261028/SubTerra.Tests/TestResults/ci-validation.trx`.

Новый запуск GitHub Actions в рамках этой проверки не создавался: исправления находятся в локальной ветке `codex/fix-ci-and-scan-regressions` и ещё не отправлены на GitHub.
