# Локальная разметка сцены

Экспериментальный модуль **Point Transformer V3 / ScanNet-20** присваивает классы точкам цветного скана помещения. Он использует опубликованные предобученные веса, а не MLP плоскостей и не детектор людей YOLOX. Новое обучение на пользовательских сканах в этом модуле пока не выполняется.

## Установка и запуск

Из корня репозитория в PowerShell:

```powershell
.\scripts\Setup-SceneAi.ps1
dotnet run --project .\SubTerra\SubTerra.csproj
```

Установщик создаёт окружение Python 3.12 в `%LOCALAPPDATA%\SubTerra\SceneAi`, устанавливает зафиксированные версии зависимостей и загружает веса. Нужны интернет и несколько гигабайт свободного места. Если `uv` отсутствует, установщик скачивает фиксированную версию и проверяет SHA-256. При наличии совместимой NVIDIA используется CUDA; библиотека поддерживает CPU, но его скорость здесь не измерена. Проверено на Windows с RTX 4060 8 ГБ, PyTorch 2.10.0+cu128 и point-transformer-v3 0.1.2.

После установки распознавание работает локально с `HF_HUB_OFFLINE=1`. Сканы не отправляются на сервер. В GitHub передаются код и установщик; большие веса скачиваются из публичного источника при установке на другом ПК. Повторный запуск установщика использует кэш. Маркер `ready.json` содержит версии и сведения о весах.

В приложении: войдите как администратор, импортируйте цветной скан в режиме помещения, откройте **Анализ → ИИ-разметка сцены → Распознать сцену**. Для PLY правильно укажите единицы и ось высоты; GLB преобразуется из метров/Y вверх автоматически. Видимые сканы должны быть совмещены.

Раздел изначально свёрнут. Выберите область, нажмите «Показать область», проверьте её в 3D и подтвердите или исправьте класс. Пропущенную часть можно выделить двумя противоположными углами инструментом измерения и разметить отдельной областью. Отмена возвращает предыдущий результат. Новое распознавание заменяет текущую разметку; эту операцию также можно отменить.

## Результат и ограничения

- Классы модели: стены, пол, шкафы, кровати, стулья, диваны, столы, двери, окна, книжные полки, картины, стойки, рабочие столы, занавески, холодильники, шторки душа, унитазы, раковины, ванны, другая мебель. **Людей и потолка в этой голове модели нет**; соответствующие классы доступны только для ручной правки. Для поиска людей остаётся отдельный инструмент YOLOX.
- Обрабатывается до 120 000 точек видимых сканов. Это выборка, а не полная сегментация каждого исходного измерения. Мелкие предметы и редкие участки могут отсутствовать. Цвета берутся из исходного скана, без пользовательского тонирования.
- Нормали оцениваются по соседям. Распознавание идёт пространственными блоками с соседним контекстом; это отличается от полного эталонного протокола ScanNet. Наклон скана, плохие цвета, пропуски, необычная геометрия и восстановление нормалей могут ухудшить результат.
- Порог softmax 0,55 переводит слабые ответы в «Не определено». Это оценка модели, не измеренная вероятность правильного ответа. Уверенная ошибка всё ещё возможна.
- Соседние точки одного класса объединяются в области по сетке 0,2 м. **Область не является подтверждённым отдельным предметом**: два стула могут склеиться, один предмет — разделиться. Число областей нельзя использовать как число объектов или людей. Мелкие компоненты отображаются как неопределённые; до 256 автоматических и 512 суммарных областей.
- Предложения модели, их оценки и ручные классы хранятся раздельно. Автоматический результат не становится эталоном обучения после сохранения. Правки пока не переобучают PTv3.
- XYZ/RGB исходного скана не изменяются. Разметка сохраняется в `.subterra` (схема 15, `scene-ai/labels.json`). Изменение геометрии, цвета, маски, видимости или положения скана делает её устаревшей. Отмена может восстановить актуальность. Старые сборки приложения схему 15 не читают; текущая сборка читает предыдущие схемы.
- Модель предназначена для комнат. Классы грунта, породы и крепи тоннеля требуют отдельного набора данных и модели; этот модуль их не распознаёт.

## Проверки и последующее обучение

В локальном прогоне на трёх существующих проектах (GLB, PLY и коридор) обработано по 120 000 точек, проверено сохранение и повторное открытие результата. Время на RTX 4060 составило примерно 8–14 секунд на анализ без импорта и сохранения; повторный запуск GLB дал ту же разметку. Это проверка работоспособности, **не измерение точности**. Визуальная проверка выявила ошибки на людях, потолке и плотно расположенной мебели. Контрольной 3D-разметки для mIoU и полноты классов пока нет.

Следующий этап — разметить представительные области реальных сканов, отделить целые независимые съёмки для проверки и сравнить исходные и дообученные веса по IoU/полноте каждого класса, доле неопределённых ответов и ложным срабатываниям. PLY и GLB одной съёмки должны попадать в одну группу. Подсчёт отдельных объектов требует проверки масок экземпляров, а людей — отдельной модели или совместной проверки 2D/3D. Псевдометки этой модели нельзя считать ручным эталоном.
