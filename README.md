# SubTerra

SubTerra — прототип приложения для трёхмерного исследования и картографирования пещер, тоннелей и помещений. Цель проекта — превращать данные сканирования в цифровую модель пространства: с границами комнат, измерениями и распознанными объектами.

**C# · .NET 9 · WPF · HelixToolkit / DirectX 11**

## Что уже есть

- 3D-просмотр, прогулка по виртуальным пещерам и симуляция LiDAR-сканирования.
- Импорт облаков точек и готовых сеток из PLY, ASC, XYZ и TXT; свободный полёт по скану.
- Несколько сканов в проекте, изменение их положения, очистка и отмена действий.
- Измерения, метки, срез облака, сохранение проектов и экспорт PLY.
- Геометрический поиск пола, стен и потолка с проверкой классов оператором.
- План одной выпуклой комнаты: примерные площадь, периметр и высота, вид сверху и границы в 3D.
- Гостевой просмотр, инструменты администратора и восстановление несохранённых данных.

## Что планируется

- Ручная коррекция планов, проёмов и границ помещений.
- Несколько комнат, этажи и цифровая модель здания.
- Совмещение дополнительных сканов и обновление существующей модели.
- Распознавание предметов с помощью ИИ и ONNX Runtime.
- Подключение реального сканера и работа с большими объёмами данных.

Сейчас проект работает с симуляцией и импортированными файлами. Прямое подключение оборудования и нейросети ещё не реализованы; геометрические результаты требуют проверки человеком.

Для запуска откройте [решение](SubTerra/SubTerra.sln) в Visual Studio с поддержкой WPF и .NET 9. Нужны Windows и DirectX 11.
