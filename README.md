# Subterra

**Просмотр реальных 3D-сканов и моделирование LiDAR-сканирования.**

Subterra — Windows-приложение для просмотра облаков и сеток, измерений и симуляции сканирования пещер. Реальные сканы предметов, макетов и зданий открываются независимо от виртуальных сцен.

**Стек:** C# · .NET 9 · WPF · HelixToolkit / DirectX 11.

## Что уже работает

- Импорт ASC / XYZ / TXT и PLY (ASCII и binary), RGB, готовые сетки, единицы мм/см/м и ось Y/Z; до 5 млн точек и 5 млн треугольников.
- Геометрические кандидаты пола, стен и потолка для одного помещения: отдельная подсветка и опорные контуры; [учебный пример](samples/indoor-analysis/README.md). Результат пока временный, классы проверяет оператор.
- Автоматический обзор и скорость полёта по размеру модели, габариты, сохранение полного реального скана с цветами, сеткой и метками.
- Три виртуальные сцены: пещера Аврора, шахтная выработка и лавовый тоннель.
- Потоковое сканирование с настройкой дальности, плотности, частоты и скорости симуляции.
- Три вида карты: каменная поверхность, облако точек и окраска по высоте.
- Прогулка от первого лица с ограничениями пола и стен.
- Свободный полёт по облаку, сохраняемые настройки мыши и скорости, выход в обзор без сброса места осмотра.
- Адаптивное качество при движении, FPS и средний интервал между кадрами.
- Координаты выбранной точки, измерение расстояний, свои метки и произвольный срез облака.
- Пауза, продолжение, перестановка и поворот датчика в текущем сеансе.
- Временная шкала, сохранение и загрузка `.subterra`, экспорт точек в PLY.
- Отмена загрузки, сохранения и экспорта; недавние файлы и отдельная копия восстановления каждые 20 секунд.
- Локальный администратор, гостевой просмотр и подтверждение перед потерей несохранённых данных.

В демонстрационных сценах измерения синтетические. Реальные данные импортируются после захвата и сшивки в ПО сканера. Прямой драйвер MQ, SLAM, реконструкция произвольного облака и распознавание ИИ пока не реализованы. Метки задаются сценарием или пользователем вручную.

**3DeVOK MQ:** [пошаговое сканирование, экспорт из Studio и импорт в SubTerra](docs/3devok-mq.md).

## Быстрый запуск

Нужны Windows, .NET 9 SDK и видеосистема с поддержкой DirectX 11. Для разработки в Visual Studio установите нагрузку **«Разработка классических приложений .NET»**. В текущей среде используется Visual Studio 2022.

1. Откройте [SubTerra/SubTerra.sln](SubTerra/SubTerra.sln).
2. Выберите `SubTerra` запускаемым проектом и восстановите NuGet-пакеты.
3. Нажмите **F5**. При запуске появится готовая демонстрационная карта.

Или выполните из корня репозитория:

```powershell
dotnet restore .\SubTerra\SubTerra.sln --locked-mode
dotnet run --project .\SubTerra\SubTerra.csproj
```

`global.json` выбирает SDK семейства .NET 9. Точные версии зависимостей сохранены в `packages.lock.json`; для восстановления используется публичный nuget.org.

## Управление и первый вход

| Действие | Управление |
|---|---|
| Вращать / сдвигать / приближать карту | ЛКМ / ПКМ / колесо |
| Вернуть общий вид | Home |
| Начать осмотр изнутри | «Прогулка внутри», затем щелчок по сцене |
| Идти / осматриваться / ускориться | WASD или стрелки / мышь / Shift |
| Летать в облаке точек | «Точки» → «Свободный полёт» → щелчок по сцене; WASD, Q/E вниз/вверх, колесо — скорость |
| Освободить курсор / выйти из прогулки | Tab / Esc |
| Режим презентации | F11 |
| Запуск или пауза сканирования | Пробел, после входа администратором |
| Сохранить / сохранить как / открыть | Ctrl+S / Ctrl+Shift+S / Ctrl+O |

Гостю доступны демонстрационные сцены, открытие файлов, просмотр и прогулка. Для сканирования, изменения параметров, очистки, сохранения и экспорта нажмите **«Вход администратора»**.

При первом входе задайте свой пароль для логина **`admin`**: от 10 до 128 символов. Предустановленного пароля нет. Учётная запись хранится локально в профиле Windows; после перезапуска требуется новый вход.

Подробные инструкции по сканированию, ролям и перестановке датчика — в [руководстве](docs/user-guide.md).

## Проверка проекта

```powershell
dotnet restore .\SubTerra\SubTerra.sln --locked-mode
dotnet build .\SubTerra\SubTerra.sln --configuration Release --no-restore
dotnet test .\SubTerra.Tests\SubTerra.Tests.csproj --configuration Release --no-build --no-restore
```

[GitHub Actions](.github/workflows/ci.yml) выполняет эти проверки на Windows при отправке в `master` или `main` и создании pull request. Проверки данных и команд дополняются [ручным протоколом интерфейса](docs/validation/ui-smoke.md) и [замером производительности CPU](docs/validation/performance.md). Длительная проверка GPU и интерфейса остаётся в плане.

```text
  Services/            Накопление, хранение, экспорт и доступ

SubTerra.Diagnostics/  Воспроизводимый CPU-замер

```
