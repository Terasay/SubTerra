# Учебные файлы импорта

Оба файла созданы программно; это не образцы реального экспорта MQ.

1. В SubTerra нажмите **«Импорт скана»** и выберите `block-100x60x40-mm.ply`.
2. Единицы — **миллиметры**, вверх — **Z**. Локальное начало можно оставить включённым.
3. Ожидаются 8 точек, 12 треугольников, габариты **0,100 × 0,060 × 0,040 м**. Переключите **«Сетка»**, чтобы увидеть цветной блок; **«Точки»** покажет восемь углов.
4. Расстояние между `(0,0,0)` и `(0.1,0,0)` — **100 мм**, пространственная диагональ — около **123,288 мм**.
5. Второй файл, `points-with-normals-and-rgb.asc`, содержит те же восемь углов с нормалями и цветом, без граней. Для него выберите столбцы **«3DeVOK: X Y Z Nx Ny Nz R G B»**. Режим сетки будет недоступен.

Сохраните в `.subterra`, откройте заново и проверьте сохранение цветов и меток. Экспорт из SubTerra в PLY уже содержит **метры**: при его повторном импорте выбирайте метры, а не миллиметры.

[Полная инструкция для MQ](../../docs/3devok-mq.md).
