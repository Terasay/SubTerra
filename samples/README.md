# Учебные сканы

Все примеры синтетические: они созданы для проверки приложения и не являются реальными измерениями.

| Файл | Импорт | Ожидаемый результат |
|---|---|---|
| [Цветной блок](scan-import/block-100x60x40-mm.ply) | Миллиметры, Z вверх | 8 точек, 12 треугольников, размер 100 × 60 × 40 мм |
| [Точки с нормалями и RGB](scan-import/points-with-normals-and-rgb.asc) | Миллиметры, Z вверх; столбцы `X Y Z Nx Ny Nz R G B`, RGB 0–1 | Те же 8 углов без сетки |
| [Учебная аудитория](indoor-analysis/classroom-meters-zup.ply) | Метры, Z вверх | Комната 6 × 5 × 3 м, столешница, шум и отдельные выбросы |

Для проверки комнаты найдите поверхности и подтвердите пол, потолок и четыре стены. Столешницу оставьте неопределённой. Во вкладке «Анализ → Комната» постройте план: ожидаются около **30 м²**, **22 м периметра** и **3 м высоты**.

При повторном импорте PLY, экспортированного из SubTerra, выбирайте **метры**.

Для проверки перед подключением сканера выполните из корня репозитория в PowerShell на Windows с .NET 9 SDK:

```powershell
.\scripts\Test-StudioImport.ps1
```

Скрипт собирает диагностику в Release и сверяет число точек, цвета, треугольники и габариты двух учебных файлов. Дополнительный проход с осью Y проверяет перестановку габаритов. Каждый скан проходит через сохранение и повторное открытие проекта во временной папке. Успешная проверка выводит три строки `PASS`.

Первый **зарегистрированный экспорт из Studio** можно проверить тем же путём. После сборки замените имя файла, единицы и ось на фактические настройки экспорта:

```powershell
dotnet run --project SubTerra.Diagnostics -c Release --no-build -- --check-studio-export "C:\Scans\export.ply" mm z
```

Результат — JSON с числом точек и треугольников, габаритами в метрах и признаком `ProjectRoundTrip`. Сравните габариты с контрольным предметом, расположенным вдоль осей. Для текстового облака укажите раскладку последним аргументом: `xyz` (только координаты, по умолчанию), `xyz-rgb` (0–255) или `xyz-normal-rgb` (цвета 0–1 после нормалей). Код возврата 0 означает, что файл прочитан и проект сохранил измерения. Точность сканирования, подключение и калибровка требуют отдельной проверки на устройстве.
