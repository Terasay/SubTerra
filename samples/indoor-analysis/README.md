# Учебная комната для анализа структуры

`classroom-meters-zup.ply` — синтетическое цветное облако, не измерение реального помещения.
Комната 6 × 5 × 3 м, четыре стены, пол, потолок и столешница на высоте 0,8 м.
В файле 3747 точек, небольшой шум координат и отдельные выбросы. Меток классов в PLY нет.

## Как попробовать

1. Импортировать PLY: **единицы — метры, ось высоты — Z**. Исходное смещение можно убрать.
2. Войти как администратор и вернуться в общий обзор.
3. В панели объектов открыть **«Структура помещения» → «Найти поверхности»**. Начальный допуск — 0,025 м.
4. Ожидаются семь крупных плоскостей: кандидаты пола, потолка, четырёх стен и неопределённая столешница.
5. Выбрать строку для отображения её опорного контура; выключить подсветку для сравнения с исходными цветами.

Подсветка показывает точки выборки, а не новую сетку. Контур выпуклый: он может перекрывать отверстия и промежутки;
его площадь не является точным обмером поверхности. Все классы требуют проверки человеком.
Анализ временный, не записывается в `.subterra` и сбрасывается при изменении проекта.

Автотесты также проверяют комнату без потолка, маски, перенос/поворот скана и столешницу без комнаты.
Успех на этом примере не подтверждает качество на настоящем скане корпуса.
