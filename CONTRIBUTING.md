# Работа над Subterra

Приложение и тесты требуют Windows и .NET 9 SDK. Решение находится в `SubTerra/SubTerra.sln`.

## Локальная проверка

Из корня репозитория:

```powershell
dotnet restore .\SubTerra\SubTerra.sln --locked-mode
dotnet build .\SubTerra\SubTerra.sln --configuration Release --no-restore
dotnet test .\SubTerra.Tests\SubTerra.Tests.csproj --configuration Release --no-build --no-restore
```

Для запуска интерфейса:

```powershell
dotnet run --project .\SubTerra\SubTerra.csproj
```

## Изменения

- Создавайте отдельную ветку для задачи, например `feature/scanner-controls` или `fix/session-loading`.
- В описании изменений указывайте проблему, полученное поведение и выполненную проверку. Для интерфейса полезны снимки до и после изменения.
- Проверяйте роль администратора, отмену операций и сохранение уже полученных данных при изменении команд сканирования.
- Для изменений обработки данных добавляйте проверки поведения и граничных случаев. Оформление и тексты достаточно проверить через окно.
- Сохраняйте модульность: данные в `Models`, источники в `Simulation`/`Services`, визуализация в `Rendering`, ввод в `Navigation`.
- Не добавляйте в Git сборки, локальные настройки IDE, пароли, файлы учётной записи и результаты сканирования. `.gitignore` уже содержит соответствующие правила.

## Зависимости

`global.json` выбирает стабильный SDK семейства .NET 9, включая установленное обновление. Версии пакетов записаны в `.csproj`, полный граф — в `packages.lock.json` каждого проекта. CI восстанавливает пакеты с `--locked-mode`.

При намеренном обновлении пакетов измените `.csproj`, выполните `dotnet restore .\SubTerra\SubTerra.sln --force-evaluate`, проверьте сборку и тесты. Добавляйте изменённые lock-файлы в тот же коммит.

## Ограничения прототипа

Реальный LiDAR, SLAM и распознавание ИИ пока отсутствуют. Виртуальная поверхность использует геометрию симулятора. Не описывайте демонстрационные данные как реальные результаты измерения или работы нейросети.

Актуальные задачи — в [плане разработки](ROADMAP.md), результаты проверок — в [документации](docs/validation/ui-smoke.md).
